Suite 상세

설정

  • Backbone: openvla/openvla-7b-finetuned-libero-{spatial,object,goal,10}, 완전 고정. 학습 대상은 Actor/Critic MLP(2.16M)뿐.
  • 잔차: z ∈ ℝ²⁵⁶, Δh = z·B (B = LM head 의 action-token 256 행), h′ = h + Δh 로 7-step greedy decode.
  • BC: LIBERO 데모로 critic 만 return-to-go 회귀 (frame stride 15, 3 epoch). Actor 는 warm-start(출력 0 근방).
  • PPO: 5,000 env step (buffer 512 → 10 iteration), lr 1e-4→1e-5, target KL 0.05, entropy per-dim.
  • 이번 run 의 변경: value loss 를 return 의 running variance 로 정규화, actor/critic grad 개별 클리핑. 9월 run 에서 critic grad norm 500–2000 으로 매 스텝 클리핑되던 문제를 고침(이번 run critic grad norm ≈ 1).
  • Baseline 성공률은 2026-09-01 측정값(같은 체크포인트·평가 코드·seed 7, task 당 20 에피소드). 이번 run 에서 task 당 1 에피소드로 재실행해 영상과 정합성만 확인.
