예시 에피소드: 마지막 프레임

Goal · 와인병을 랙에 놓기 (45 → 70%)

Frozen OpenVLA · 실패 (300 step)

OLIVE · 성공 (144 step)

Long · 모카포트 두 개를 스토브에 (25 → 20%)

Frozen OpenVLA · 실패 (520 step)

OLIVE · 성공 (494 step)

에피소드 하나씩 고른 예시. 모카포트 task 는 평균으로는 OLIVE 가 낮음(25 → 20%). 전체 영상 40쌍은 상세 결과 페이지에 있음.

대표 예시 두 개입니다. 둘 다 baseline이 실패하고 OLIVE가 성공한 에피소드를 골랐기 때문에 일반적인 모습은 아닙니다. 특히 모카포트 task는 평균으로 보면 OLIVE가 25%에서 20%로 오히려 낮습니다. 전체 task의 영상 비교는 상세 결과 페이지에서 볼 수 있습니다.
