방법: 행동 기저 위의 잠재 잔차

Frozen OpenVLA-7B

이미지 + 지시문 → 마지막 hidden state h

Actor MLP

h → z ∈ ℝ²⁵⁶ (학습 대상)

Δh = z · B

B = LM head 의 행동 토큰 256행

h′ = h + Δh

7-step decode → 로봇 행동 7차원

2.16M

학습 파라미터 (Actor 1.11M + Critic 1.05M)

0.03%

7B backbone 대비 비율, backbone 은 완전 고정

OLIVE는 backbone을 건드리지 않습니다. 마지막 hidden state에 잔차 Δh를 더하는데, 그 잔차를 LM head의 행동 토큰 256개 행이 만드는 부분공간으로 제한합니다. 학습하는 것은 256차원 z를 내는 Actor와 가치를 예측하는 Critic, 합쳐 2.16M 파라미터뿐입니다.
